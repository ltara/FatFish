# 肥鱼 Windows 客户端 — 使用说明

买断安装包：**FatFish-Setup.exe**（Windows 客户端安装包）。  
费用说明：软件买断价以闲鱼商品页为准（当前 ¥99）；对话所用的 AI 接口费用由您自备的 API Key 账户承担，与软件买断分开。

## 您需要准备

1. 一台 Windows 10 / 11 电脑  
2. 一个**专用小号** QQ（强烈建议不要用主号）  
3. 您自己的 DeepSeek API Key（在 DeepSeek 开放平台自行申请与充值）

## 安装

1. 双击运行 `FatFish-Setup.exe`  
2. 若弹出 Windows 智能筛选 / 未知发布者提示，选择「仍要运行」（正式版将逐步补签名）  
3. 按向导完成安装  
4. 若提示需要安装 **QQ**，请先安装官方 QQ，再继续  
5. 安装结束后，从开始菜单打开「肥鱼」窗口

## 首次使用

1. 打开「肥鱼」窗口后，阅读并勾选**风险告知**（不勾选将无法继续）  
2. 在左侧进入「设置」，粘贴您的 DeepSeek API Key，点「保存到本机」  
   - Key **只保存在本机**，不会上传到肥鱼服务器（本产品无云端托管）  
   - 保存后窗口不会显示完整 Key  
3. 如需 QQ 远程陪伴，在左侧进入「平台」，展开 QQ 设置，启用并确认账号风险，再按提示扫码登录、绑定你的主人账号。此功能可选，不影响本机对话。
   - 若手机 QQ 弹出安全验证，请在手机上确认  
   - 登录过程在肥鱼窗口内完成，无需另外打开系统浏览器  
4. 回到「状态」页，确认「API Key」为已保存、「本机服务 / 登录服务」为可达后即可使用

## 验收：私聊是否正常

1. 用**另一个** QQ 号，添加您登录的小号为好友  
2. 向小号发送：`你好`  
3. 数秒内应收到自动回复  

若无回复：在「状态」页查看是否已填 Key、登录服务是否可达；仍异常可运行安装目录中的诊断工具。

## 数据存在哪里

- 配置与 Key：本机用户目录下的肥鱼数据文件夹  
- 默认**不上传**聊天与 Key  
- 卸载时可选择是否删除本地数据

## 风险须知（摘要）

- 使用非官方方式登录 QQ 存在**封号**风险，请只用小号  
- 请勿将 API Key 发给任何人（包括卖家客服）  
- 本软件不提供代充 Key、不代管账号  

## 常见问题

**Q：杀毒软件拦截？**  
加入信任或暂时允许后重试；以您本机安全策略为准。

**Q：只能私聊吗？**  
当前版本以私聊自动回复为主；群聊等能力后续再开。

**Q：换电脑？**  
需重新安装并重新登录；Key 请自行备份（勿发聊天工具）。

**Q：状态页提示服务未启动？**  
请从开始菜单重新打开「肥鱼」，或运行安装目录中的启动项后再点「刷新状态」。
