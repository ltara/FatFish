## 范围与边界

- 用户明确允许隔离数据的无窗口截图，不允许操作现有试用窗口或实际数据。

- 没有启动或关闭肥鱼程序，没有安装、构建、发布或改变激活信任锚。

## 选定方向与改动

北极星仍是让人一眼看出状态和下一步动作。保留深侧栏、浅台面、13px 正文、固定导航顺序和既有主色，没有新增图片、图标、框架或外部资源。

1. 页头与侧栏增加一致的留白，选中项不再贴边；悬停与选中有不同底色。
2. 首页删除重复的人格和详细状态入口，保留模块操作；详细状态使用原生折叠标识。
3. 对话撤去外围大卡片，审批卡片成为主要操作区域；收紧输入区无内容的反馈留白，普通尺寸保持输入区固定在底部。
4. 状态文字、主按钮、删除操作改善对比度。主按钮复用既有较深蓝灰色，白字从 3.54:1 提高到 4.56:1，不改变品牌色。
5. 人格空库沿用唯一一组新建/导入操作；公开资料区减少重复留白。长名称、错误和说明允许换行，保留字号；有效窄视口下多行说明提升为 13px。
6. 共享键盘焦点、禁用按钮状态、导航 `aria-current`、对象行状态播报与减少动态效果规则。

动效只保留既有颜色反馈，删除暂停按钮的位移，不加页面转场、出场动画或循环装饰。删掉首页重复文字和空库重复按钮/过时说明，模型费用、隐私和审批提示没有删减。

规格先登记在 `DESIGN.md` §5.8，再修改实现。主进程、接口、审批、存储和激活逻辑未改。
