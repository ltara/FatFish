## 使用

手动完全退出旧开发版，再双击仓库根目录的 **肥鱼（开发版）.lnk**。现有快捷方式直接进入同一个源码启动器，无须重新生成。命令行等价入口：

```powershell
npm.cmd --prefix D:\workspace\FatFish\app\electron-ui run dev
```

沿用原开发数据时继续使用原快捷方式或已有 `--data-root` 参数；不要换目录、复制 Key 或删除许可证。首次启用这项能力需要重开一次，以后修改下面的界面文件不必逐次重开应用。

| 修改位置 | 保存后的行为 |
| --- | --- |
| `app/electron-ui/renderer/styles.css` | 自动同步并替换样式表，不刷新页面 |
| `app/electron-ui/renderer-src/` 的组件、样式与导入资源 | 自动重新编译；只有样式变化时替换样式，结构或脚本变化时安全刷新页面 |
| `app/electron-ui/renderer/` 的九个业务控制器 | 自动同步；安全刷新整个页面，避免重复挂载事件和定时器 |
| 主进程、`preload.js`、主进程辅助模块、Core、依赖 | 只提示手动重开开发版；不自动重启或替换后台 |

`renderer/index.html`、`renderer/assets/ui.min.*` 是生成文件，勿手改；监听器忽略生成输出以避免循环构建。普通 `npm start` 和正式安装包不启用本功能。

## 刷新保护

- 正在发送消息、测试/保存模型、等待工具审批或 IPC 操作时暂缓刷新。
- 未发送对话、模型设置、密钥、激活码、公开资料等未保存输入，以及打开的人格编辑/导入页、配对与删除确认会暂缓刷新。右下角显示等待原因；保存、清空或取消后自动继续。
- 样式替换不打断上述操作。新样式加载成功才移除旧样式；失败保留旧样式并提示再次保存。
- 只恢复当前导航页名，不缓存草稿、Key、消息或用户数据。整页刷新不会自动发送消息、测试模型或重放审批。
- 编译失败不发布新资源，当前页面保留；错误修正后再次保存即可。命令行可单独执行 `npm run build:ui` 查看编译错误。
- 构建串行并合并连续保存；跨多次保存保留“尚需整页刷新”的版本信息，避免后续样式更新掩盖组件更新。资源复制期间不刷新。

这不是 React Fast Refresh：React 当前只负责静态呈现壳，业务仍由既有控制器管理。安全整页刷新用来销毁旧控制器，不承诺保留未保存的 React 状态；有草稿时先等待而不是强制刷新。

## 隔离与交付边界

入口继续使用既有开发激活签发器和独占代码副本，只同步界面代码。数据目录、激活服务私钥、正式信任锚与 Core 代码不热替换。仅开发副本的 preload 包装现有 IPC 调用以计数，不读取/记录参数与结果；新增开发桥只提供待处理数量和固定刷新请求。

主进程校验刷新来源必须是当前主窗口主 frame，版本必须有效。仍用 `file://`、既有 CSP、`sandbox: true`、`contextIsolation: true` 和 `nodeIntegration: false`，不接 HTTP 开发服务器，不放宽导航或安全权限。开发 host、注入脚本、监听器都不在正式 `build.files` 中；生产 preload 无开发桥，生产 renderer 不安装开发刷新状态函数。

退出时先关闭监听并等待正在进行的构建，再清理经过路径校验的代码副本；不清理开发数据和服务端密钥。开发激活与数据路径说明见 `DEVELOPMENT_ACTIVATION.md`。
