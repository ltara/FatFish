## 2. 用户手动启动

先从现有肥鱼的托盘菜单选择 **退出**（右上角关闭可能只是隐藏），不要同时保留旧普通窗口和开发窗口。

### 推荐：双击开发快捷方式

本机仓库根目录的 **`肥鱼（开发版）.lnk`** 是直接双击的入口，不需要手动敲命令。它运行当前源码并自动处理开发激活服务，启动时编译界面并监听改动，不安装、不打包、不自动激活或试聊；辅助进程隐藏，不要求先打开终端。

本次创建的快捷方式显式沿用现有 `fatfish-m3e-live-UPJfi5` 开发数据，与上一轮提供的命令一致，不复制 Key、不迁移或删除数据。该数据仍在旧临时目录，不应误认为已经迁到默认持久目录。若该目录被系统清理，启动会报错，不会悄悄换成新数据。原普通窗口须先手动退出。

快捷方式由 `scripts/create-development-shortcut.ps1` 创建，调用 `scripts/launch-development.ps1`，最终与 `npm run dev` 进入同一个源码启动器。`.lnk` 含本机绝对路径，不入库、不进正式包；移动仓库或换机器时再生成一次。创建脚本只写快捷方式，不启动程序或改用户数据。其他开发者首次可运行（不带 `-DataRoot` 时使用默认独立持久目录）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\workspace\FatFish\scripts\create-development-shortcut.ps1
```

### 可选：命令行排障

命令行不是本地开发的使用门槛，仅作为排障入口。一般开发启动，默认使用独立数据目录：

```powershell
npm.cmd --prefix D:\workspace\FatFish\app\electron-ui run dev
```

要沿用当前普通开发窗口的模型配置/记录，本次已知目录是旧开发临时目录 `fatfish-m3e-live-UPJfi5`，可以显式选择它；不复制、不导出模型 Key：

```powershell
npm.cmd --prefix D:\workspace\FatFish\app\electron-ui run dev -- --data-root "$env:TEMP\fatfish-m3e-live-UPJfi5"
```

此临时目录名仅适用于当前机器现有开发会话，不是其他用户的默认路径。显式目录必须已经存在 `config.json`。如果目录里已有不属于开发签发器的许可证，入口会拒绝，不自动覆盖或删除。

看到窗口名 **「肥鱼 · 开发版」** 后，手动粘贴固定码并点激活。不要在旧普通窗口中尝试这个码。

默认数据位置：`%LOCALAPPDATA%\FatFishDevelopment\data\`。服务器和数据都不是普通正式版目录；指定 `--data-root` 时只有数据目录改变，服务器目录不变。

## 3. 验签边界

- 本地签发器仅监听 `127.0.0.1`，不部署云服务，不请求模型；固定码也不是模型密钥。
- 开发私钥在 `%LOCALAPPDATA%\FatFishDevelopment\activation-server\development-signing.key`，仅属于开发激活服务端；不写入 Git、复制客户端或构建资源。文件使用私有创建模式，Windows 继承当前用户目录权限，勿把该目录放到共享位置。
- 同一服务端密钥跨启动保留，避免每次启动使已有开发许可证失效。不要擅自删除重建；这不是正式生产私钥。
- 每次启动复制一份受控应用源码，只在复制的公开信任模块中写开发公钥和本机签发地址。Main/Core 的算法和独立验签照旧，客户端不包含私钥，也不自动写许可证或确认风险。
- 源码原始信任模块不变；开发工具在 `app/electron-ui/scripts/`，现有 `build.files` 不包含这些脚本。正式构建仍要求正式公开配置，不能用本机回环地址发布。
- 开发客户端代码副本在 `client-runs/`，退出后只清理自己的受控代码副本；不清理数据和服务器密钥。服务端关闭后，已经签发且匹配设备的许可证仍按既有机制本地验签。
- 本机开发签发器不替代正式 Worker/D1 的发码、设备数、作废/解绑业务，不据此宣称 M5-1 或正式服务上线完成。
