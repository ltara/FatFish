## 仍须满足的前置/关联门禁

1. **M3-E 真实 QQ**：小号登录、主号配对、连续对话/重启续聊、暂停、换人格、陌生人与冒充拦截，以及真实 p50/p95/内存。回环不能替代，见 M3_E2E。
2. **M4 原生最终复验**：记忆/公开资料、人设、提醒最小化提示、工作区选择、模型设置及激活后整合。旧版本窗口证据不能套用到新 Main/renderer。
3. **M4-10**：只有 PowerShell 5.1 的干净 Win10；当前开发机的 PS5.1 检查不等于干净系统证据。
4. **M4-11**：50 个完整真实人格轮次；当前实发 1/50 次、完成 0 轮即遇错停止。代理 gzip 缺陷已离线修复，但真实首请求根因未确认。剩余最多 49 次须用户再次允许，不重放/重置原账本，见 M4_PERSONA。
5. M4-8 已有锁定 SDK 模块缺失证据，可按路线图允许的失败分支留 v1.x；不能以用户禁用窗口作为此能力不支持的依据。

- 用户仍禁止窗口操作，不能启动 UI、浏览器/Computer Use 或 Electron smoke；本轮只使用 Node、普通对象和包内 Node 模式。
